V34 - Finanzas ERP: expediente, edición e histórico

- Cambia el enfoque de pagos para que todos los registros importantes sean consultables.
- Los conceptos de pago ahora se abren como expediente lateral con contexto completo.
- Los proveedores se pueden abrir desde el nombre para ver histórico, contratos, validaciones y pagos relacionados.
- Solicitudes de pago permiten revisar expediente, editar datos y consultar anexos.
- Autorizaciones usan expediente de pago antes de aprobar/rechazar.
- Pagos programados permiten seleccionar varios pagos y programar un lote con una sola fecha.
- Se evita usar prompt para fecha de programación; ahora se usa campo de fecha visible.
- Pagos realizados permiten abrir la solicitud ligada para revisar contexto e histórico.
- Se agregan patrones de UX tipo banca/ERP: panel lateral, tarjetas de riesgo, anexos, bitácora e histórico similar.
