V49 - Operación e inmuebles

1. Arrendamientos / Inmuebles
- Solo los inmuebles que pertenecen a plazas o agrupaciones tipo plaza se muestran en bloques desplegables.
- Terrenos, casas, departamentos, oficinas y otros inmuebles independientes se muestran en una tabla normal sin minimización.
- Se conserva la vista mapa real y expediente de inmueble.

2. Operación
- Se recupera el flujo de Operación con los módulos trabajados previamente:
  - Checklist / Calidad.
  - Configurar obra.
  - Estimaciones.
  - Equipo construcción.
  - Consulta técnica.
- Se corrige la navegación para que Configurar obra, Estimaciones y Consulta técnica abran sus módulos reales anteriores.
- Se agrega Resumen operación dentro de TRITON OS con cruces operativos:
  - pagos/estimaciones de obra abiertos;
  - contratos de obra;
  - trámites activos;
  - equipo de construcción;
  - pendientes operativos ligados a pagos;
  - trámites que afectan operación.

3. Inicio / identidad
- El encabezado base del sistema cambia a TRITON OS para que el sistema no se perciba como solo Control de Calidad.
